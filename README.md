# SPY NETWORK — لعبة الجاسوس أونلاين

مشروع أولي قابل للتشغيل للعبة الجاسوس العربية، بواجهة 2D داكنة بالأزرق والرمادي. الواجهة في `index.html`، وخادم اللعب والحسابات في `server.js`.

## الموجود في هذه النسخة

- حسابات باسم مستخدم وكلمة مرور، مع تخزين كلمة المرور على هيئة hash باستخدام `scrypt` وليس كنص صريح.
- قائمة أصدقاء وطلبات صداقة واردة وصادرة.
- غرف برمز من 5 أحرف/أرقام، وتدعم **3 أو 4 أو 5 لاعبين فقط**.
- دعوة الأصدقاء المتصلين إلى غرفة الانتظار.
- جاسوس واحد يختاره الخادم عشوائيًا، وكلمة لا تصل إلا إلى المواطنين.
- دور تلميحات، ثم تصويت، وفرصة تخمين أخيرة للجاسوس إذا صوّت اللاعبون على مواطن.
- تصميم متجاوب للهاتف والكمبيوتر، مع أنيميشن CSS خفيف.

## تشغيل المشروع على الكمبيوتر

1. ثبّت Node.js إصدار 18 أو أحدث.
2. فك ضغط المشروع في مجلد.
3. افتح نافذة Terminal أو CMD داخل المجلد.
4. نفّذ:

   ```bash
   npm install
   npm start
   ```

5. افتح `http://localhost:3000` في المتصفح.
6. أنشئ حسابًا، ثم افتح اللعبة من متصفح آخر أو جهاز آخر لإنشاء حساب لاعب ثانٍ.

يحتاج الاختبار المحلي إلى اتصال إنترنت أثناء `npm install` لتنزيل مكتبة `ws` المطلوبة للسيرفر.

## جعل الأصدقاء يلعبون عبر الإنترنت من أماكن مختلفة

لا يكفي إرسال ملف HTML إلى الأصدقاء؛ يجب أن يكون **السيرفر نفسه منشورًا على استضافة يمكن الوصول إليها عبر الإنترنت** وتدعم Node.js وWebSocket (اتصالات `wss://` خلف HTTPS). انشر المشروع وفق تعليمات مزوّد الاستضافة، واجعل أمر التشغيل `npm start` والمنفذ يعتمد على متغير البيئة `PORT`.

اضبط `DATA_DIR` على مجلد تخزين دائم في الاستضافة حتى لا تضيع الحسابات عند إعادة النشر. إذا كانت الاستضافة توفر قرصًا مؤقتًا فقط، فقد تفقد قاعدة بيانات الحسابات عند إعادة تشغيلها. الغرف والجولات والجلسات النشطة محفوظة في الذاكرة وستنتهي عند إعادة تشغيل السيرفر؛ سيحتاج اللاعبون إلى تسجيل الدخول مرة أخرى.

## ملفات مهمة

- `index.html` — واجهة اللعبة كاملة.
- `server.js` — HTTP + WebSocket ومنطق الحسابات والأصدقاء والغرف والأدوار.
- `package.json` — اعتماديات المشروع وأمر التشغيل.
- `Dockerfile` — خيار لتشغيل المشروع في بيئة تدعم Docker.

## ملاحظات قبل الاستخدام العام

هذه نسخة أولى قابلة للتجربة وليست خدمة تجارية مدققة أمنيًا. قبل نشرها على نطاق عام، أضف تخزينًا دائمًا مناسبًا، وحدودًا لمحاولات التسجيل وطلبات الصداقة، ومراقبة للسيرفر، وسياسة خصوصية/شروط استخدام. لا تضع كلمات المرور الحقيقية التي تستخدمها في خدمات أخرى داخل هذا المشروع.
